================================================================================
Release notes (newest first)
================================================================================

### v1.4.0

· OCR 间距更忠实原图：数字与标点间不再错误插入空格（如 3.14、v1.0、12:30），并保留原文缩进。
· 托盘右键菜单移除渲染不稳定的圆角，改用 Windows 原生渲染。
· 优化内部依赖，安装包更小、下载更快。

· OCR 間距更忠實原圖：數字與標點間不再錯誤插入空格（如 3.14、v1.0、12:30），並保留原文縮排。
· 系統匣右鍵選單移除渲染不穩定的圓角，改用 Windows 原生渲染。
· 最佳化內部相依元件，安裝包更小、下載更快。

· OCR spacing is more faithful to the original: no more stray spaces inside numbers and abbreviations (3.14, v1.0, 12:30), and indentation from the source image is preserved.
· Tray right-click menu drops the unstable rounded-corner rendering in favor of native Windows rendering.
· Slimmed down internal dependencies - smaller install package, faster download.

· OCR の間隔がより原文に忠実に：数字や略記の途中にスペースが誤挿入されなくなりました（3.14、v1.0、12:30）。元画像のインデントも保持されます。
· トレイの右クリックメニューは、描画が不安定な角丸をやめて Windows ネイティブの描画に切り替えました。
· 内部依存を最適化し、インストールパッケージをより小さく、ダウンロードを高速化しました。

### v1.3.1

· 修复设置中"开机自启动"选项无效的问题。
· OCR 排版判断更保守。

· 修復設定中「開機自啟動」選項無效的問題。
· OCR 排版判斷更保守。

· Fixed the "Start with Windows" setting not taking effect.
· OCR layout detection is now more conservative.

· 設定の「OS 起動時に自動スタート」オプションが機能しない問題を修正。
· OCR のレイアウト判定をより保守的にしました。

### v1.3.0

· OCR 更快更准：识别速度大幅提升，尤其是小尺寸截图，识别更跟手；同时小图的识别准确度也更好。

· OCR 更快更準：辨識速度大幅提升，尤其是小尺寸截圖，辨識更跟手；同時小圖的辨識準確度也更好。

· OCR is faster and more accurate: recognition speed is up notably - especially for small screenshots, it feels more responsive - and small screenshots recognize more accurately too.

· OCR はより速くより正確に：認識速度が大幅に向上し、特に小さなスクリーンショットでより追従感が出ました。同時に小さな画像の認識精度も向上しています。

### v1.2.0

· 内置编辑器新增状态栏缩放滑条，拖动即可调整图片的查看大小，操作更接近系统自带的看图器。
· OCR 对原文排版的还原更准确，换行、段落与缩进更贴近原图，减少了段落被误合并或误拆分的情况。
· 修复若干小问题，并优化了编辑器体验。

· 內建編輯器新增狀態列縮放滑桿，拖曳即可調整圖片的檢視大小，操作更接近系統內建的看圖軟體。
· OCR 對原文排版的還原更準確，換行、段落與縮排更貼近原圖，減少了段落被誤合併或誤分割的情況。
· 修正若干小問題，並改善編輯器體驗。

· Added a zoom slider to the built-in editor's status bar - drag to adjust the image's viewing size, much like the system image viewer.
· OCR better preserves the original layout. Line breaks, paragraphs, and indentation now match the source image more closely, with fewer paragraphs merged or split incorrectly.
· Various small fixes and editor improvements.

· 内蔵エディターのステータスバーにズームスライダーを追加。ドラッグするだけで画像の表示倍率を調整でき、OS 標準の画像ビューアーに近い操作感です。
· OCR のレイアウト再現性が向上。改行・段落・インデントがより元画像に忠実になり、段落の誤結合・誤分割が減りました。
· いくつかの細かな不具合を修正し、エディターの使い勝手を改善しました。
