========================================
HushSnap
========================================

【简体中文】

HushSnap 是一款连接了截图与 OCR 的桌面工具，本地运行、不传数据，日常截图识别跟手。

按下快捷键（默认 Alt+Q），框选区域，截图即复制到剪贴板，右下角随即滑出一张缩略图：

左击缩略图 → 弹出 OCR 识别结果
左击按钮 → 编辑图片，或钉在桌面上
拖拽缩略图 → 拖进任意目标窗口即可存图
右键缩略图 → 唤出更多功能菜单

不需要就放着它消失，尽量不打扰你。

OCR 识别出的文字会整理成更易读的排版，不会像多数 OCR 软件那样把文字挤成一团，识别结果弹窗支持直接编辑。

特性：
- 本地运行，不会向任何服务器发送你的截图或识别内容
- 支持多台不同分辨率显示器混用的多屏环境截图
- 免登录、免注册，不依赖其他软件
- 常驻系统托盘，智能管理内存占用
- 右键托盘图标进入设置，快捷键可自定义

语言支持：
支持简体中文、繁体中文、英文、日文的界面和文字识别，效果已验证良好；其中中文与日文还支持竖排文字识别。其他语言可能有一定识别效果，但不作保证，部分语言暂不支持。

开源：
代码开源（GPL-3.0），源码见 github.com/tcita/HushSnap

【繁體中文】

HushSnap 是一款連接了截圖與 OCR 的桌面工具，本地運行、不傳資料，日常截圖辨識跟手。

按下快速鍵（預設 Alt+Q），框選區域，截圖即複製到剪貼簿，右下角隨即滑出一張縮圖：

左鍵點擊縮圖 → 彈出 OCR 辨識結果
左鍵點擊按鈕 → 編輯圖片，或釘在桌面上
拖曳縮圖 → 拖進任意目標視窗即可存圖
右鍵點擊縮圖 → 喚出更多功能選單

不需要就放著它消失，盡量不打擾你。

OCR 辨識出的文字會整理成更易讀的排版，不會像多數 OCR 軟體那樣把文字擠成一團，辨識結果彈窗支援直接編輯。

特色功能：
- 本機運行，不會將你的截圖或辨識內容傳送至任何伺服器
- 支援多台不同解析度顯示器混用的多螢幕環境截圖
- 免登入、免註冊，不依賴其他軟體
- 常駐系統匣，智慧管理記憶體占用
- 右鍵系統匣圖示進入設定，快速鍵可自訂

語言支援：
支援簡體中文、繁體中文、英文、日文的介面與文字辨識，效果已驗證良好；其中中文與日文還支援直排文字辨識。其他語言可能有一定辨識效果，但不作保證，部分語言暫不支援。

開源：
程式碼開源（GPL-3.0），原始碼見 github.com/tcita/HushSnap

【English】

HushSnap is a desktop tool that bridges screenshots and OCR — runs entirely locally, no data ever leaves your machine, and stays responsive for everyday capture-and-recognize workflows.

Press the hotkey (default Alt+Q), select an area, and the screenshot is copied to your clipboard instantly. A thumbnail then slides in from the bottom-right corner:

Left-click the thumbnail → shows the OCR result
Left-click the button → edit the image, or pin it to the desktop
Drag the thumbnail → drop it into any target window to save the image
Right-click the thumbnail → opens a menu with more options

If you don't need it, just leave it — it fades away on its own without getting in your way.

Recognized text is automatically reformatted into a cleaner, more readable layout, instead of being crammed together the way most OCR tools do — and the result popup is directly editable.

Features:
- Runs entirely locally — your screenshots and recognized text are never sent to any server
- Supports multi-monitor setups with mixed resolutions
- No login, no registration, no dependency on other software
- Runs in the system tray with smart memory management
- Right-click the tray icon to open settings; hotkeys are fully customizable

Language Support:
Interface and text recognition are supported in Simplified Chinese, Traditional Chinese, English, and Japanese, all well tested. Chinese and Japanese also support vertical text recognition. Other languages may work to some extent but are not guaranteed, and some are not supported yet.

Open Source:
Source code is open under GPL-3.0, available on github.com/tcita/HushSnap

【日本語】

HushSnap は、スクリーンショットと OCR をつなぐデスクトップツールです。すべてローカルで動作し、データが外部に送信されることはなく、日常的なスクリーンショット認識に軽快に応えます。

ホットキー（デフォルトは Alt+Q）を押して範囲を選択すると、スクリーンショットが即座にクリップボードにコピーされ、画面右下からサムネイルがスライドして表示されます：

サムネイルを左クリック → OCR 認識結果を表示
ボタンを左クリック → 画像を編集、またはデスクトップにピン留め
サムネイルをドラッグ → 任意のウィンドウにドロップして画像を保存
サムネイルを右クリック → その他の機能メニューを表示

不要な場合はそのまま放置すれば自動的に消え、極力邪魔をしません。

OCR で認識したテキストは読みやすいレイアウトに整形され、多くの OCR ソフトのように文字がぎゅうぎゅうに詰め込まれることはありません。認識結果のポップアップはその場で編集も可能です。

特徴：
- ローカルで完結し、スクリーンショットや認識結果をサーバーに送信することはありません
- 解像度の異なる複数モニターを組み合わせたマルチディスプレイ環境でのスクリーンショットに対応
- ログイン・登録不要、他のソフトウェアへの依存なし
- システムトレイに常駐し、メモリ使用量をスマートに管理
- トレイアイコンを右クリックして設定画面を開き、ホットキーはカスタマイズ可能

対応言語：
インターフェースと文字認識は簡体字中国語・繁体字中国語・英語・日本語に対応しており、動作を確認済みです。中国語と日本語は縦書きテキストの認識にも対応しています。その他の言語は一定の認識精度が期待できる場合がありますが、保証はできません。また一部の言語は現時点では未対応です。

オープンソース：
