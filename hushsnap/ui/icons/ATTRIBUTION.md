# Corner ornament assets — attribution

## corner_butterfly.png

Butterfly artwork by **gustavorezende**
(https://openclipart.org/artist/gustavorezende).

Sourced via rawpixel (image id 6333004), which marks the asset
**"Free for Personal and Business use."**

The PNG in this directory is a processed derivative of the original: the
subject was de-padded (transparent margins cropped, no non-empty pixels
removed), rescaled, and repositioned onto a 1024×1024 canvas so its solid
body region lands on the thumbnail's top-left corner. No recoloring — the
original olive-green palette is preserved.
